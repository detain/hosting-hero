# Game Logos — Title Candidates as Abstract Marks (typeset-after law)

<!-- spec: hosting_game.md §0.5 working-title candidates (UPTIME / Five Nines / HOSTILE TRAFFIC / Bare Metal chosen from the ratified shortlist), §8.10/identity register (era tokens: 1998 amber-square vs 2026 cyan-rounded), Hue Ledger discipline (marks must not collide with state colors when used in-world), docs/adr/0001 (iso-pixel world: the mark must survive being rendered tiny inside a pixel scene). -->

BRANDING family. METHOD LAW for this whole file, stated once and enforced per block: image models garble lettering, so **never ask the model for the wordmark** — every prompt below generates the GEOMETRIC EMBLEM ONLY ("no letters, no words, no numerals"), and the real title text is typeset afterward in vector software next to the chosen mark. Each candidate title gets its own category of emblem thinking: 3 variations each — (A) minimal flat vector ideation, (B) iso-diorama miniature object version, (C) engraved/embossed physical plate version. Outputs here are design-exploration sheets, not final assets; expect to redraw the winner.

---

**PICK CRITERIA:** every candidate passes the no-letters audit first — zoom the full plate; any glyph-shaped accident, any watermark pseudo-text, rejected. Then the 24px silhouette test (§8.16 law): each mark flattened to black on white at favicon size must retain its single thesis gesture (UPTIME's notch, FIVE NINES' terminal bead, HOSTILE TRAFFIC's overshoot, BARE METAL's open crown). Then the collision audit: does the mark's dominant color conflict with Hue Ledger state meaning if used in-world (a loading-screen watermark must never read as alert-amber or threat-magenta at a glance)? Finally the typeset rehearsal: paste a real wordmark drawn in vector software beside the emblem at three scales — the geometry that survives marriage to honest lettering is the winner; the model's job was always the mark, never the name.
