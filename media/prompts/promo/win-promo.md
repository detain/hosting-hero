PROMO family, 3:2 scene plates (hero-format siblings). The inverse of the loss catalog: wins in this game are quiet, procedural, and deeply felt precisely because nobody watching would notice them. Each block stages one correct action completing perfectly. Warmth comes from competence, never from spectacle; Hue Ledger stays strictly honest — green is verified-healthy, gold is money, amber appears only as warm afterglow or task light, never as alert in a win frame.

**PICK CRITERIA:** every win plate must pass the "would a veteran player feel this?" test — these images dramatize procedural correctness, so the enemy is spectacle-creep: any seed that looks like a celebration poster has misread §9.9's canon (the unglamorous correct actions get the best art precisely because nobody else would animate them). Greyscale pass: each composition needs one dominant value gesture (V1 gold pool, V2 dark window-with-one-LED, V3 continuous tape arc, V4 single vertical impact vector, V5 receding notch-line) surviving luminance compression. Thumbnail Test at 128px: V2 must still look like nothing is happening — that is its subject; if it becomes legible-dramatic at small size it has failed upward. Series law: these five must rhyme with the loss catalog's hand — same ink temperature, same miniature-world tilt-shift, so a promo strip of wins and losses reads as one world's two weathers.
