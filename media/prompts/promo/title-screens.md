### V4 — Mastery Is Boredom

```
POSITIVE: painterly-editorial poster in strict 2:3 vertical format, the quietest image possible and completely warm about it: early morning machine room drawn as a serene isometric diorama, every single rack LED comb a uniform restful green #4FC46A, zero amber, zero red, no incident anywhere; in the mid-ground a lone operator lounges sideways in a swivel chair at a small folding table propped in the aisle, feet up on a cable spool used as an ottoman, playing a handheld game or doing a crossword on paper, mug steaming; a cat sleeps on a warm patch of raised floor near a vent; morning light from one high window lays a soft honest rectangle across the floor through slow-drifting air, dust like pollen. A hand-painted quality to surfaces — this building has been loved for twenty years. Something gently comic but never mocked: a small rubber duck sits on the table for moral support, a lawn chair has been relocated here for maximum comfort. The composition places all interest in the lower two-thirds; the upper third is the clean high wall and window-light haze, a calm void reserved for a typeset title. The joke is legible without any caption: they have optimized themselves into leisure — boredom as the highest achievement. No text, no letters, no numbers, no watermark, no UI captions, the crossword grid must be an abstract pattern not solvable letters.
NEGATIVE: disaster, alerts, amber or red lights, dystopian server-room menace, people working, screens showing readable content, sad tone, cinematic blue horror grade, cluttered floor hazards, meme references
size: 2400x3600
aspect: 2:3
style: editorial-illustration
background: scene
variations: tone is the pick gate (§0.5 recognition comedy, never parody — the operator is content, never lazy or mocked); reject any seed where the figure reads as negligent (asleep at the wheel) rather than serene — the infrastructure must visibly need nothing from them. ```
```

**PICK CRITERIA:** these are title plates — the first test is typeset simulation: drop a placeholder rectangle into the reserved upper third of each candidate; any seed whose highlights fight that box is rejected regardless of beauty. Greyscale pass: each composition must read as three value zones (void / mid interest / focal detail) with the focal point below the frame's vertical midpoint. Thumbnail Test at 128px: V1 must still show "small person, huge racks"; V2 must still show two opposing tides on one road; V3's diagonal wipe must still split; V4 must still read as calm (a single green field, no false alarm pixels). Series law: all four must feel drawn by the same hand — same ink temperature, same tilt-shift signature — or only one survives to actual use.
